# LexiVault 启动与试用

这份源码包含已经打包的 `dist/`。研究计划可以在当前浏览器中编辑、导入、保存和备份；登录注册页沿用已定稿版本。本文依据本轮实施方案与源码编写，最终验证状态见交付 README。

## 1. 启动

安装 **Node.js 22 或以上版本**。解压源码后，在含有 `package.json` 的项目根目录打开终端，运行：

```bash
npm start
```

仅体验交付的打包版本，无需先运行 `npm install`，也不需要安装 Neo4j 或配置模型。

- 工作空间：<http://127.0.0.1:8000/home.html>
- 文献发现与来源配置：<http://127.0.0.1:8000/discover.html>
- 直接进入研究计划：<http://127.0.0.1:8000/plans.html>
- 六个功能的日间／夜间设计：<http://127.0.0.1:8000/designs.html>
- 登录注册：<http://127.0.0.1:8000/index.html>

按 `Ctrl+C` 停止服务。真实账号接口尚未接入，本地试用直接访问工作空间即可。

也可以使用 Python，在项目根目录运行：

```bash
python -m http.server 8000 --directory dist
```

随后仍使用上面的 `127.0.0.1:8000` 地址。部分系统需将 `python` 改为 `python3`。请通过 HTTP 访问，避免直接双击 HTML 导致数据库、模块或 PDF 解析受限。

## 2. 先体验一份计划

首次打开新浏览器数据库时，会建立四份**可编辑示例**。它们保存到此浏览器，可以修改、归档或放入回收站。

1. 选择“秋季科研推进计划”，修改标题和正文。
2. 选中文字，试用加粗、高亮、字号、字体、颜色、对齐和列表；也可插入待办、表格、图片或链接。
3. 等顶部显示“已保存到此浏览器”，刷新后检查内容。`Ctrl+S`／`⌘S` 也可主动保存。
4. 点击“我的计划”旁的加号新建文档，或在更多菜单中使用计划模板／副本。

右侧“文档信息”可设置状态、分类、标签、开始与截止日期；较窄屏幕可通过右上按钮展开。状态包括“待开始、进行中、已完成、已归档”。截止日期不能早于开始日期。

“日程”按**整份计划的起止日期**展示，未设置日期的计划列在下方。正文待办支持勾选与完成进度，目前没有逐条待办的独立日期、系统闹钟或后台提醒。

## 3. 导入自己的文档

唯一的主导入入口是左侧计划列表底部的 **“导入文档 / 任意附件”**，也可以把文件拖到页面唤起同一对话框。

- **每个文档新建一份计划**：常见格式转换为可编辑正文，原始文件同时保留。不能转换的格式会新建一份带原始附件的计划。
- **添加为当前计划的附件**：仅保存原件，不替换当前正文。先选好目标计划再操作。

选文件后点击“开始导入”，查看逐文件结果。导入弹窗也提供 Word、Markdown、PDF 示例下载；源码 `dist/examples/` 还包含 CSV、TXT 和 RTF。DOCX、ODT、RTF、Markdown、TXT、HTML、CSV、JSON 和有文本层的 PDF 有对应转换路径；旧版 `.doc`、扫描 PDF 和未知二进制文件可保留原件。复杂 Word 版面不会无损还原，完整范围见 [IMPORT-FORMATS.md](IMPORT-FORMATS.md)。

原件在正文下方“附件”区域下载。编辑转换后的正文不会修改电脑上的原始文件；移除浏览器附件也不会删除电脑原件。

## 4. 双向链接与关联图

在正文输入 `[[`，输入另一份计划名称，从建议中选择；也可使用工具栏的内部链接按钮。输入完整 `[[计划名称]]` 同样可以形成链接。`[[计划名称|显示名称]]` 可使用别名。

重名时请在弹窗中依据分类与标识选择具体文档；目标不存在时可以新建并链接。选择明确目标后使用稳定 ID 关联，避免只靠标题猜测。

右侧展示“引用了这份计划”和“这份计划链接到”；点击可跳转。“关联图”呈现正文中的明确链接，可查找计划或标签、拖动和缩放，点击节点回到文档。近两周标签关联依据编辑时间，不代表真实研究投入时长。

阅读笔记和研究计划是不同文档上下文；这里的备忘文档不替代文献阅读页右侧带原文定位的阅读笔记。

## 5. 归档、回收站与导出

更多菜单可归档或移入回收站。左侧状态筛选选择“回收站”，打开文档后恢复即可继续编辑；回收站内容保留原件。归档用于收起阶段性计划，可在状态中重新改为待开始或进行中。

右上导出菜单提供：

- **Word DOCX**：保留常见正文样式、列表和表格；图片以提示占位，图片内容请用 HTML 或原件查看。
- **Markdown**：便于继续编辑与迁移；字号、颜色等富文本属性会简化。
- **HTML**：保留受支持格式和正文内嵌图片，可独立打开。
- **完整备份 ZIP**：包括所有计划、日期、状态、正文、明确内部链接、回收站内容及原始附件。

恢复时从同一导入入口选择 ZIP，并使用“每个文档新建一份计划”。备份会**合并为新副本**，计划标题加“（导入）”，重新分配标识并映射已绑定链接，不覆盖现有计划。重复恢复会再次产生副本。

## 6. 数据保存在哪里

计划与附件保存在当前浏览器、当前站点来源的 IndexedDB 中，不会自动发送给模型，也不是已经同步到云端或电脑指定目录。

请固定使用同一浏览器、协议、主机和端口。`127.0.0.1`、`localhost`、不同端口与在线站点各自有独立数据。换地址后看不到原计划时，先返回原地址检查，不要立即清理浏览器数据。

重要内容请导出完整备份。隐私模式、清除站点数据、浏览器配额或系统清理可能影响保存。出现“保存失败”时，当前草稿仍保留在页面；先导出或另存副本，再处理存储问题。多页同时修改发生冲突时，也可选择另存副本，或在确认后载入已保存版本。

## 7. 当前交付范围

桌面端六个功能页使用同一套图标侧栏，图标内容、顺序和间距保持一致。鼠标移到侧栏空白区域会显示方向光标，点击空白处可展开带文字的侧栏，再次点击空白处可收起；点击功能图标继续导航。展开状态会跨页面保留。手机通过顶部导航按钮展开文字抽屉。侧栏收起时，底部日夜按钮显示当前主题图标，点击可切换；侧栏展开或打开手机抽屉后，显示带“日间／夜间”文字的分段按钮。展开和收起不会改变主题，当前选择跨页面保留。

六个唯一导航入口是：科研智能体、文献发现、文献阅读、研究计划、主题图谱、知识库管理。文献阅读设计使用“目录—原文—阅读笔记”三列。

文献发现现可试用五个来源的选择与条件凭据、下载路径配置、示例检索与队列。顶部使用紧凑搜索工具栏，在资料类型下方打开“来源与凭据”统一勾选平台与设置访问方式；年份支持悬停显示数量、双端时间轴拖动与精确输入。下载路径仅从“确认获取到知识库”打开的确认窗口配置。结果列表与队列局部滚动，底部可翻页及选择每页条数；窄屏通过三个工作区按钮切换。点“确认获取到知识库”后选择知识库和目录，再保存或导出方案草稿；不实际下载或入库。详细平台字段与官方依据见 [DISCOVERY-SOURCES.md](DISCOVERY-SOURCES.md)。研究计划继续支持本地保存、导入、附件、链接、日程和导出。其他新增科研界面仍展示设计／待接入状态；真实文献获取、持续解析、Neo4j、个人知识检索和模型服务尚未连接。完整产品方案见 [LexiVault-project-spec.md](LexiVault-project-spec.md)。

## 8. 修改源码与检查

仅运行打包版本无需执行此节。要修改源码时，在项目根目录依次运行：

```bash
npm ci
npm ci --prefix qa
npm run build
npm test
```

首次安装需要网络。计划模块源码位于 `src/plans/`；构建更新 `dist/`，再运行 `npm start` 预览。静态资源检查可执行 `npm run check`，需要 Python 3。

# 本地文献阅读更新

文献阅读现在需要本地后端。在项目根目录运行 `backend\.venv\Scripts\python -m backend`，打开 <http://127.0.0.1:8000/reader.html>。点击“打开本地目录”选择工作空间，导入 PDF 后即可阅读并编辑本地 Markdown 笔记。Windows 默认新建目录位于 `%LOCALAPPDATA%\LexiVault\workspaces`，页面显示实际路径。
