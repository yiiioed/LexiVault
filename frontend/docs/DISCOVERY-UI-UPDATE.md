# 文献发现前端优化 · v0.4.2

## 布局调整

根据本轮四张参考截图，删除文献发现原有的独立顶部栏，以及搜索框下方的来源选择行和“前端交互预览”行。标题与搜索合并为一条紧凑工具栏，下面直接进入筛选、检索结果、获取队列三栏，缩减非核心内容占用。

结果、筛选与队列继续各自滚动；结果区底部固定保留分页和每页条数控件，页面底部紧接元数据说明。左侧略加宽以容纳年份组件，队列略收窄，把空间优先留给检索结果。窄屏继续使用三个工作区切换按钮，手机导航按钮保留在新工具栏中。

## 年份筛选

按提供的 OpenAlex 截图，使用灰色柱形、深色时间轨道和圆形双端滑块，保留项目暖色背景与日夜主题。

- 鼠标悬停在柱形上，浮层显示年份和该年文献数量；键盘聚焦也显示相同信息。
- 拖动任一端点时，年份标签和选中柱形即时变化；松开后提交筛选。键盘可操作原生滑块。
- 两个端点不能交叉。点击时间轨道会移动最近的端点，可继续拖动；取消轨道拖动会恢复已应用的范围。
- 柱形支持方向键浏览，点击或按 Enter 可只看该年。
- 展开“输入年份”可精确填写。输入超出现有刻度时扩展图表范围，非法范围在控件旁提示；重置恢复默认范围和刻度。

柱形数量只来自现有六条本地示例。年份统计遵循关键词、来源、资料类型和开放获取条件，但忽略自身的年份筛选，避免拖动后统计被裁掉。连续年份中的零结果也保留。没有使用参考图片里的数量或生成虚构文献来填充图表。

## 来源与下载入口

来源勾选统一放进“来源与凭据”弹窗，与访问方式一起应用。取消不会修改已生效的选择。资料类型下方仍保留该入口；下载路径继续只有确认入库弹窗内的入口。

## 源码结构

项目使用原生 ES Modules、HTML、CSS 和 esbuild。页面结构从源码生成，`dist/` 包含可直接启动的构建文件；`dist/discover.css` 本身也是项目维护的样式源。

| 文件 | 职责 |
| --- | --- |
| `src/discover/page.js` | 紧凑工具栏、筛选组件、年份控件和来源配置弹窗 |
| `src/discover/year-range.js` | 年份浮层、滑块、轨道与键盘交互 |
| `src/discover/model.js` | 年份分面统计、检索筛选、分页、状态与方案校验 |
| `src/discover/app.js` | 筛选联动、来源统一应用、队列与配置流程 |
| `dist/discover.css` | 三栏空间分配、图表与滑块、响应式、日夜配色 |
| `scripts/pages.mjs` | 仅文献发现不生成原独立顶栏，其他页面结构保留 |
| `qa/discovery-*.test.mjs` | 文献发现模型与 DOM 交互验证 |

## 查看与验证

在项目根目录运行 `npm start`，访问 <http://127.0.0.1:8000/discover.html>。压缩包包含完整源码和已构建 `dist/`，仅查看无需安装依赖。

1. 悬停年份柱形，或用键盘聚焦后按方向键，查看年份数量浮层。
2. 拖动两个时间端点，松开后查看结果；展开精确输入可试用更大的年份范围。
3. 在“来源与凭据”中启用 OpenAlex，点击应用；设为每页五篇可验证第二页与跨页队列保留。
4. 缩窄窗口，检查工作区切换、手机导航和日夜主题。

构建、静态资源、CSS 语法检查和全部 **105 项自动化测试**通过，其中 29 项覆盖文献发现。真实浏览器截图、视口几何、鼠标／触屏拖动与实机视觉验收尚未完成；DOM 事件测试不替代这些验证。

本轮只修改前端、构建产物、测试与说明，没有新增后端检索、下载、凭据验证或知识库写入。
