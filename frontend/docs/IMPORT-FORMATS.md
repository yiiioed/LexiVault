# 研究计划：导入、导出与文件限制

本说明描述本轮研究计划模块。正文转换在浏览器内进行，原始文件保存到此浏览器的 IndexedDB；未接入云端转换、OCR、模型或 Neo4j 服务。格式路径存在不代表所有复杂文档已经通过验证，最终测试情况见交付 README。

## 导入入口与两种模式

点击左侧计划列表底部 **“导入文档 / 任意附件”**，选择文件，再点击“开始导入”。拖入文件会打开同一个对话框，不会无提示替换当前正文。

| 导入模式 | 结果 |
| --- | --- |
| 每个文档新建一份计划 | 尝试转换支持的正文；原件作为新计划附件保存。无法转换时创建说明正文并保留原件 |
| 添加为当前计划的附件 | 保存原始文件，不做正文转换，不替换当前计划内容 |

支持多选，结果逐文件反馈。超出单文件上限的文件会被拒绝；符合附件上限但正文转换失败的文件，会尝试保留原件并说明原因。回收站中的计划须先恢复，才能继续编辑或添加附件。

## 可转换的常见格式

| 格式 | 当前转换内容 | 需要人工核对的部分 |
| --- | --- | --- |
| DOCX | 常见段落、标题、加粗／斜体／下划线／删除线、字号与颜色、列表、表格，以及支持的嵌入图片 | 复杂样式继承、分页、页眉页脚、修订、公式、浮动对象、图片定位 |
| ODT | 常见标题、段落、列表、表格和部分文字样式 | 专有样式、页面布局、图片和特殊对象不保证还原 |
| RTF | 常见文本、段落、加粗／斜体／下划线／删除线、字号、颜色与高亮 | 老编码、复杂表格、嵌入对象、页眉页脚；中文文件建议检查或先转 DOCX／UTF-8 TXT |
| MD / Markdown | 支持的 Markdown 结构进入编辑器，原件保留 | 不同方言、自定义插件、复杂 HTML；外链图片不会自动加载 |
| TXT | 按行转换为可编辑段落 | 建议使用 UTF-8；纯文本没有原始字体和高亮可恢复 |
| HTML / HTM | 清洗后的常见段落、格式、列表、表格和安全的内嵌图片 | 脚本、事件、嵌入页面、任意 CSS、远程图片等会移除或转为提示 |
| CSV | 逗号分隔的表格，支持带引号字段、字段内换行和双引号转义 | 不执行单元格公式，不作为 Excel 工作簿导入 |
| JSON | 格式化后作为结构化文本进入正文 | 不自动执行数据，不猜测任务字段；完整备份恢复请使用专用 ZIP |
| PDF（有文本层） | 按页提取文字形成可编辑草稿 | 版面、阅读顺序、公式、表格、图像和脚注，不能直接编辑原 PDF 布局 |

**旧版二进制 `.doc` 不做假转换。** 扫描 PDF 没有可提取文本时，本轮不会执行 OCR。图片、PPT、XLSX、压缩包、代码和其他未知格式可以按允许大小保存原始附件；附件可下载不等于其内部内容可编辑。

所有格式都会保留原件；编辑转换后的正文不会回写原文件。这里的“类似 Word”指正文编辑与常见样式，不代表完整 Word 排版兼容。

## 资源限制

1 MiB = 1,048,576 字节。下列值来自本轮 `src/plans/model.js` 与格式处理决策；浏览器可用配额仍可能更小，最终以交付代码和页面提示为准。

| 项目 | 本轮限制 | 结果 |
| --- | --- | --- |
| 单个原始附件 | 50 MiB | 超限不导入 |
| 尝试转换为正文的单文件 | 20 MiB | 在附件上限内可改为保留原件 |
| 单份正文／提取文字 | 1,000,000 字符 | 超限停止转换或拒绝无效文档 |
| 单份 PDF 文字提取 | 100 页 | 更多页数需拆分，或只保存原件 |
| DOCX／ODT／备份等 ZIP 展开 | 100 MiB，最多 2,048 条目 | 预检不通过时拒绝解析；普通文档仍可保留原件 |
| CSV | 最多 1,000 行、50 列 | 超限不转为表格 |
| 手动插入正文图片 | 单张 5 MiB；PNG、JPEG、GIF、WebP | 更大的图片可用普通附件模式 |
| 计划数量 | 最多 2,000 份 | 达限时需先整理资料并保留备份 |
| 完整 ZIP 备份 | 压缩包 100 MiB，并受 100 MiB 展开预算和条目数限制 | 导出预算包含清单与附件，超限时需整理资料 |

密码保护的 ZIP 文档、ZIP64、异常路径、过多条目和损坏 XML 不进入正文解析。移除文件密码后再导入；未能解析不意味着原件已被修改。

## 导出选择

| 导出格式 | 适合用途 | 保存与降级范围 |
| --- | --- | --- |
| Word `.docx` | 在 Word 等软件中继续编辑常见正文 | 标题、常见文字格式、列表、待办、表格和链接；正文图片以提示占位，不完整还原页面 |
| Markdown `.md` | 纯文本迁移与版本管理 | 常见文本结构、待办及 `[[内部链接]]`；字体、字号、颜色、高亮和复杂表格可能简化 |
| HTML `.html` | 独立查看格式化正文 | 受支持样式及正文内嵌图片；外部字体需由系统提供 |
| 完整 ZIP | 保留数据并恢复试用环境 | 所有计划、结构化正文、状态、日期、分类、标签、绑定链接、回收站内容和原始附件 |

前三种导出针对当前计划正文，不等于导出所有附件。图片通过工具栏插入后，HTML 包含内嵌图片，完整备份同时保留原件；只下载 Word 文件不能作为图片备份。

## ZIP 备份与恢复

从右上导出菜单选择“完整备份（含所有附件）”。包内包含清单和原始附件数据。导出与恢复都受资源预算约束：清单与附件的展开总量、ZIP 最终大小以及条目数都要符合上限。重要资料也可以逐份导出正文并下载原件。

恢复时选择“每个文档新建一份计划”，导入由 LexiVault 生成的 ZIP：

1. 检查备份格式、文档结构、附件及大小。
2. 为导入计划和附件生成新标识，标题加“（导入）”。
3. 映射备份内部已绑定的计划链接，使副本之间保持关系。
4. 合并保存，不覆盖浏览器现有计划；再次恢复同一包会再次创建副本。

普通 ZIP 没有受支持的备份清单时，只作为原始附件处理，仍受普通单附件 50 MiB 上限约束；请勿把任意 ZIP 当成可恢复备份。备份损坏或缺少附件时显示错误，不以不完整数据替换现有资料。

## 数据与校验状态

导入正文会移除不安全 HTML、危险链接和自动外部加载资源。浏览器数据库按协议、主机和端口隔离；在线站点、本地不同地址和不同浏览器不会自动共享计划。请定期备份，不要把浏览器缓存当作唯一资料存档。

本文依据本轮实现与恢复的实施决策整理，格式样例、备份、页面流程与回归测试已执行，通过情况见 [TEST-REPORT.md](TEST-REPORT.md)。发现转换差异时，先查看保留的原件，再修订可编辑正文。
