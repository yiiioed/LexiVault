# LexiVault 工作空间界面设计说明

这组界面基于重新梳理的科研流程设计，不引用旧项目文档。登录注册页已经定稿，本组设计只覆盖登录后的工作空间。所有图中内容均为“示例 · 界面设计”，不代表真实搜索结果、知识索引或智能体已经连接。

## 文件与查看方式

每个页面均提供 1600 × 1000 PNG 预览，以及保留文本、矢量控件、原有 LexiVault 标识的可编辑 SVG。直接打开 PNG 即可查看；在设计工具编辑 SVG 时请安装随附的 `assets/NotoSansSC.ttf` 字体，避免中文替换。SVG 同时声明了该相对字体路径。

## 导航与信息结构

工作空间仅保留六个唯一的主要功能入口，名称和顺序固定为：科研智能体、文献发现、文献阅读、研究计划、主题图谱、知识库管理。原“文献库”和“阅读笔记”不再拆成两个竞争入口：阅读时目录与笔记同时可见；资料导入、文件夹与索引维护统一放到知识库管理。

全局左栏宽 224px，顶部栏高 64px。通用左栏负责模块切换、工作空间选择、最近文档及外观设置；最近文档属于具体内容的快捷链接。按钮的主要动作与当前页面任务相关，不将相同的主要功能分散到多个区域。宽屏内容按任务自然展开，不使用数据看板或无关的统计卡片。

文献阅读例外：左栏收为 64px 图标轨道，将原工作空间侧栏的位置交给 256px 可展开目录树。其右侧为约 900px 原文阅读器，再右侧为 380px 阅读笔记。这是三个明确的纵向主分区：目录、原文、笔记；64px 图标轨道仅作全局切换。

## 六个页面的关键状态

### 科研智能体

内容范围在回答前显式选定。回答主体可以含比较表、证据边界与来源引用，引用点击后回到对应原文位置。没有接入模型时，应展示连接提示，不伪造智能体输出。输入框保留在底部，原文引用与当前问题一同进入上下文。

### 文献发现

从查询、来源、时间等筛选开始；结果按文献自然排列。右侧获取队列负责确认入库位置与全文可用性。全文不可获取时允许只导入元数据，同时清晰标注；禁止把“找到记录”表现为“下载全文成功”。获取时逐条显示进度、取消、重试与失败原因。

### 文献阅读

目录树支持逐层展开；中间文献有页码、缩放与原文高亮；右侧笔记支持富文本与 `[[双向链接]]`。新笔记默认给出空白可编辑区域和低干扰提示，只有用户摘录或输入后才出现正文。设计稿中的摘录展示的是已有笔记状态，保留页码和回跳原文入口。目录、中间原文、右侧笔记分别滚动，列间允许拖动调宽。

### 研究计划

固定 224px 全局导航 + 240px 文档列表 + 约 876px 编辑器 + 可折叠 260px 双向链接检查器。顶部“文档 / 日程 / 关联图”是同一份计划数据的三种视图。

- 文档：标题、状态、起止日期、标签；正文工具栏含段落级别、字号、加粗、斜体、下划线、高亮、字体颜色、列表/待办、链接、附件和撤销重做。引用文档用 `[[文档名称]]`，右侧显示入链及关联段落。
- 日程：按日期查看计划与文内待办；列表和周/月时间轴间切换。无日期的事项放入“未安排”，允许补日期。颜色表示状态，不作为科研成果或效率分数。
- 关联图：以当前计划为中心，显示真实存在的文档链接；点击节点切换文档，缺失目标以虚线和“待创建”标注；同名文档以明确 ID 区分。
- 导入：弹窗区分“转换为可编辑正文”和“保留为附件”。TXT、Markdown、HTML、DOCX 等已实现的格式才承诺转换；任意其它格式保留原文件，允许下载，明确不能直接编辑。
- 保存：输入后自动保存在本机；正在保存、已保存、保存失败有明确状态。导出提供独立文档与完整备份，不将浏览器缓存误称为永久云端存储。
- 列表：搜索、文件夹、状态筛选、创建、重命名、归档、删除与恢复；空列表提供新建/导入动作。右侧检查器可折叠，编辑区优先获得宽度。

### 主题图谱

大节点表示用户选定的关键词，外围关键词与论文按多对多关系连接。一篇论文允许连接多个关键词。图谱只表达可解释的摘要关键词匹配、已确认主题或用户指定关系；相同词语并不自动代表科学结论成立。选中节点后突出邻接边，其它关系降亮；默认限制标签密度，缩放或悬停才显示完整标题。节点详情包含摘要关键词、来源、入库状态与加入阅读动作。大规模图谱按子图查询、聚类和层级展开，避免全量标签重叠。

### 知识库管理

用文件树和处理状态行表达“本地原件 → 解析文本 → 摘要 → 检索索引”的流程。资料来源、处理队列、索引设置是本模块内部标签页。可检索、解析失败、等待核验等状态来自实际后台任务；没有后台时显示服务未连接。原始文件、提取文本、用户修订摘要与计算索引分别保留，便于追溯与重建。

## 交互、可访问性和移动端

主要操作使用梅紫底色；悬停只轻微改变底色，键盘焦点使用可见的 2px 强调色边框。主题切换过渡 160–240ms；文档切换与图谱相邻节点强调可使用短淡入，尊重系统减少动态效果设置。图谱支持键盘选择和文字关系列表备用视图。

1280px 以下优先折叠研究计划右侧检查器；1050px 以下全局侧栏收为 64px 图标轨道，文档列表可从抽屉打开。阅读器宽度不足时，“目录 / 原文 / 笔记”切换为单面板视图，保持当前文献和笔记状态；不能把三列硬压缩到不可读。移动端顶部显示模块名称与导航抽屉按钮，编辑工具栏可横向滚动，主动作保持 44px 以上触控区。日程和图谱均提供列表替代视图。

## 设计与本期实现的边界

以上六个模块均有页面设计；本期优先实现研究计划及导航整理。其余页面是后续开发的清晰目标，不应在产品中将静态示例表现为已完成的检索、模型推理或数据库能力。所有状态应依据真实连接、文件解析与索引任务反馈。


## 本轮可试用版本与设计目标的对应

研究计划已经实现文档、日程、关联图三种视图。日程当前是月历，显示整份计划的起止日期；正文待办提供勾选和完成进度，独立待办排期、周时间轴属于后续设计。计划图当前展示已解析的明确链接，未创建与同名目标通过右侧出链和链接弹窗处理。

1280px 以下默认折叠计划信息栏；680px 以下主导航和计划列表使用抽屉。其他新增模块在真实导航内展示设计预览，并明确标注服务待接入；文献阅读器三列重排、列宽拖动和真实 PDF 定位属于后续开发。


## v0.3.2 侧栏交互细化

实际代码中的六个功能页共用相同导航。保留科研智能体页的主图标形状，知识库管理采用三层资料库图标；固定图标列与行距，独立滚动历史区域。默认收起为 64px，点击侧栏空白区域展开为 224px，方向光标提示当前操作；功能链接和控件保持各自作用，宽度状态跨页面保留。此项是设计稿之后的交互迭代，原有 PNG／SVG 仍作为各功能主体布局设计参考。


## v0.3.3 日夜控件适配

日夜控件在 64px 图标栏中使用居中的单个太阳／月亮按钮，显示当前主题；展开为 224px 后变为带图标与“日间／夜间”文字的横向分段开关。选中样式、当前主题和跨页面记忆保持同步，手机抽屉采用完整分段开关。控件保留原有底部行高，不移动全局导航与账号位置。


## v0.4.0 文献发现落地

文献发现由整张图片替换为真实网页，沿用暖色／夜间主题、搜索区、左筛选、中结果、右获取队列及细线分隔。来源扩展为五个可选站点，通过同一配置窗口填写各自凭据。左侧“入库位置”改为“配置下载路径”，知识库和目录移至“确认获取到知识库”之后的窗口。原始 PNG／SVG 保留为主体设计参考。窄屏将队列放在结果下方，手机顺序展示筛选、结果、队列；没有加入数据看板。
