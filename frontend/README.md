# LexiVault 研究工作空间

登录注册页现已接入 Python 后端的本地账号接口，支持退出和用户偏好恢复；必须由 Python 服务提供页面。账号暂未接入远程服务器，密码找回邮件尚未提供。文献阅读支持只有元数据的条目，导入 PDF 可为当前条目补充全文。详见 [数据库说明](../backend/DATABASE.md)。

## 当前空间与空白初始状态

全站使用后端登记的当前工作空间，切换入口在文献阅读页。首页对话保存到对应空间的 SQLite；侧栏最近对话读取同一空间的数据。首页不再写入“分子图学习”、示例文献和示例对话；文献发现默认结果与队列为空，研究计划不自动生成示例，图谱与管理页显示实际功能尚未接入的空状态。

研究计划正文与附件已迁入本地工作空间；首次打开会迁移本空间的浏览器计划并保留原副本，支持外部文件修改与冲突保护。文献发现配置仍按工作空间 ID 使用浏览器存储。旧浏览器全局记录保留但不自动导入，以免把旧示例混入新空间。下方原型历史说明中的示例数量不再代表当前版本。

## 文献阅读：本地文件版本

文献阅读页已替换为真实三栏界面：工作空间论文列表、PDF 原文、Markdown 阅读笔记。支持本地导入、页码与缩放、选文摘录、引用跳转、本地自动保存、外部修改检测和冲突副本。

这部分需在项目根目录启动 Python 后端：`backend\.venv\Scripts\python -m backend`，再打开 <http://127.0.0.1:8000/reader.html>。只运行下文 `npm start` 可以预览其他前端页面，但不会提供阅读页的本地文件接口。安装与工作空间位置见根目录 README 和 `backend/README.md`。

后文保留原前端原型说明。研究计划仍使用浏览器本地数据库；来源检索下载和模型尚未接入。

项目包含已定稿的登录注册页、科研智能体首页、统一工作空间导航、可试用的研究计划模块，以及文献发现的完整前端配置流程。

侧栏：六个功能页共用同一套侧栏、图标与固定间距。桌面默认 64px 图标栏；鼠标移到空白区域显示方向光标，点击可切换到 224px 图文侧栏，再次点击空白处收起。功能图标保留导航行为，展开状态跨页面记忆；历史对话单独滚动。日夜控件同步适配宽度：收起显示当前主题图标，点击切换；展开显示“日间／夜间”分段按钮，保留当前选择。手机继续使用带文字的导航抽屉与完整分段按钮。

v0.4.2：文献发现移除独立顶栏、来源选择行与“前端交互预览”行，标题与检索合并为紧凑工具栏，把更多视口留给核心三栏。来源勾选收进“来源与凭据”，应用后统一生效。年份筛选参照本轮 OpenAlex 截图，加入数量浮层、双端拖动时间轴、键盘操作与精确年份输入。继续保留局部滚动、分页和日夜主题。详见 [本轮分析与改动](docs/DISCOVERY-UI-UPDATE.md) 和 [来源与试用说明](docs/DISCOVERY-SOURCES.md)。

## 直接启动

需要 Node.js 22 或以上。在项目根目录运行：

```bash
npm start
```

打开文献发现 <http://127.0.0.1:8000/discover.html>，或研究计划 <http://127.0.0.1:8000/plans.html>。交付包包含已构建的 `dist/`，仅体验无需安装依赖、配置模型或安装 Neo4j。请通过 HTTP 打开，不要双击 HTML。也可以运行：

```bash
python -m http.server 8000 --directory dist
```

固定使用相同浏览器、地址和端口，才能看到同一份本地计划。在线站点和本地启动的数据分别保存，可以用完整 ZIP 备份迁移。详细操作见 [QUICKSTART](docs/QUICKSTART.md)。

## 文献发现已实现

筛选、结果与获取队列构成固定高度工作区，保留日夜主题和共用侧栏。来源包括 Semantic Scholar、Crossref、arXiv、OpenAlex、PubMed / PMC；在左侧资料类型下方进入“来源与凭据”，勾选参与检索的平台，按来源填写 Key、联系邮箱或保留无需凭据的方式。点击“应用配置”后来源选择和访问方式一起生效，取消则保留原选择。点击“确认获取到知识库”后选择知识库和目录，并从该弹窗唯一的下载路径入口配置原始文件位置。方案可在本地保存并导出 JSON。Key、Token 与联系邮箱只在当前页面内存中使用，刷新清空，不上传或导出。

结果区支持局部滚动、页码切换和每页条数记忆；换页保留已选队列，修改筛选条件后回到第一页。窗口较窄时，通过“检索结果／筛选条件／获取队列”切换工作区，继续在局部区域内滚动。底部元数据提示紧接页面边缘。页面使用现有六条有限示例；默认三个来源显示五条，启用 OpenAlex 并选择每页五篇即可试用第二页。

搜索结果与摘要明确为有限本地示例，不代表真实论文检索、下载或入库。页面不会在填写的磁盘路径中创建文件，也不会创建真实知识库。

## 研究计划已实现

- 新建、模板、重命名、副本、文件夹分类、正文／标签搜索、排序、状态筛选、归档、回收站与恢复。
- Tiptap v3 富文本：标题、加粗、斜体、下划线、删除线、字体、字号、文字颜色、多色高亮、对齐、引用、列表、待办、表格、图片、链接、撤销／重做。
- 起止日期、状态、标签和待办完成进度；日程按整份计划的日期展示。
- 内部 `[[链接]]`、别名、输入建议、选择同名文档、创建缺失目标、计算出链／反链，以及可拖动、缩放、查找和键盘打开的计划关联图。
- 常见文档转换为可编辑正文，同时原件保留；任意其他文件可作原始附件。下载原件、移除附件、批量导入、拖入同一导入对话框。
- 本地 Markdown 自动保存、外部修改与重命名检测、保存失败反馈、跨页面版本冲突保护、草稿另存副本与载入本地版本。
- 导出 Word、Markdown、HTML，以及包含所有计划、回收站和原始附件的完整 ZIP。恢复为新副本，不覆盖现有计划，已绑定的内部关系映射到副本之间。
- 延续品牌与日夜主题；窄屏可折叠信息栏、打开计划列表和导航抽屉。

**文件支持的准确含义：** DOCX、ODT、RTF、MD、TXT、HTML、CSV、JSON 和有文本层的 PDF 有正文转换路径；复杂版式不是无损转换。旧 `.doc`、扫描 PDF、PPT、XLSX 等可保留原件，不能承诺直接编辑其内部内容。Word 导出中的图片为提示占位，HTML 与完整备份保留正文图片。详见 [IMPORT-FORMATS](docs/IMPORT-FORMATS.md)。

单附件 50 MiB，正文转换 20 MiB，PDF 100 页，正文 100 万字符，完整 ZIP 100 MiB 且受展开预算与条目数限制。仅保存原件时，选择“添加为当前计划的附件”，不会尝试解析压缩包。

计划正文与附件直接保存在当前本地工作空间；尚未提供跨设备云同步。首次打开为空白草稿，不创建示例计划；重要内容请导出完整备份。

## 保留的登录与智能体接口

登录注册页继续使用已定稿的动态光影、柔边蒙版与日夜状态，无暂停按钮。`index.html`、`auth-motion.css`、`auth-motion.js`、`auth-shaders.js` 的 SHA-256 与定稿一致；字体补齐了本轮新增界面字符。

账号接口仍由 `window.lexivaultAuth` 提供 `signIn`、`signUp`、`requestPasswordReset` 和 `openVault`；密码不持久化，未连接接口时不假装成功。本地试用可直接进入 `home.html` 或 `plans.html`。

智能体仍可接入 `window.lexivaultWorkspace.ask({question,messages,scope,documentIds,contextDocumentIds,workspaceName,modelId,signal})`，返回 `{message,citations:[{documentId}]}`。不连接时保存问题并明确显示服务未接入。引用与上下文边界沿用现有实现。

主页侧栏现在使用真实页面链接；宿主可以取消 `lexivault:navigate` 事件覆盖导航，也可监听 `lexivault:open-source` 连接原文阅读器。旧版本浏览器记录保留在原工作空间存储中，不混入新计划数据库，仍可通过主页设置导出原 JSON 备份。
