# 研究计划本地文件

启动 Python 服务后，计划文档直接读写当前工作空间中的 UTF-8 Markdown。文件树与知识库管理共用；普通笔记、研究计划、阅读笔记都可以存放在自建目录中。

点击左侧文件夹选择保存位置，再新建笔记、计划模板或导入文件。Markdown 导入直接保留一份原文件供编辑；其他格式可转换为可编辑文档并保留原件附件。附件默认放在文档旁边。标题与文件名独立，修改正文标题不自动改文件名；需要改名时使用树中的“…”操作。

```text
工作空间/
  .lexivault/library.sqlite     元数据、相对路径、哈希、版本、设置
  .lexivault/plan-docs/         与文件哈希绑定的富文本缓存
  .lexivault/history/plans/     历史快照
  用户自建目录/研究安排.md      普通文件，不要求固定目录名
```

## 外部编辑与关联

可以用 VS Code、记事本或 Obsidian 编辑任意可见目录中的 Markdown。页面每两秒检查一次，回到页面时也会检查。外部新增文件会自动进入文件树与文档索引，不要求先导入。保留 `lexivault_plan` 身份字段，重命名和移动后可以保持计划身份及内部链接；额外 YAML 属性保留，但不自动覆盖应用中的状态、日期、分类。

分类是计划属性，与磁盘目录独立。阅读笔记也可以作为同一份文档打开编辑，修改直接反映到阅读页。重复身份、无效编码或文件删除会停止覆盖，提供恢复本地版、另存副本和下载草稿。

新文件布局不自动导入旧浏览器数据库中的计划。正文来源是当前工作空间的实际文件，浏览器仅保存必要的应急草稿。

## 删除与保护

文件树和本地计划菜单的删除都将实际文件送到电脑系统回收站，应用内不再设置回收站入口。删除记录只保留原路径以协助索引；从系统回收站恢复到原位置后，文献和计划保留原身份与笔记关联。旧版本的内部回收站数据保留兼容。解除附件关联仅移除引用，原文件保留。

富文本缓存用于保留字体、颜色等结构并绑定正文哈希。外部修改后以 Markdown 正文为准重新解析，不承诺复杂排版无损往返。正文最大 8 MiB、单个附件最大 50 MiB；临时文件替换、事务和写入前检查用于拒绝常见冲突，尚无跨编辑器强制锁或自动合并。

历史不自动清理，也不是完整备份。停止服务后备份整个工作空间，包含 `.lexivault`、正文和附件。ZIP 导出包含计划结构及可读取附件，附件缺失时会提示处理。
