# 统一工作空间与真实文件树

代码目录 `D:\code\research-vault` 与资料工作空间 `D:\code\LexiVault工作空间` 是两个不同目录。通过全局侧栏的空间下拉菜单切换，首页、计划、文献和知识库管理使用同一空间。要首次登记磁盘上的已有目录，可用阅读页“导入 PDF → 打开本地工作空间”。

侧栏点击当前工作空间名称，可查看已登记的空间列表并直接切换；当前空间会标记“当前”。列表底部的“新建工作空间”填写名称后立即创建并打开，默认位置为本机配置目录下的 `workspaces/`。切换后保留当前功能页，载入目标空间内容；计划和阅读笔记会先保存，遇到保存失败或冲突时暂缓切换。

新工作空间只自动创建 `.lexivault/` 内部目录，用于 `library.sqlite`、编辑缓存、历史和升级备份。不会创建 `plans`、`notes`、`originals` 等业务目录，也不会恢复旧浏览器示例或计划。

## 文件操作

研究计划左栏和知识库管理页显示磁盘上的真实文件树。点击文件夹选择新建／导入位置；工具栏可新建文件夹、Markdown 笔记、导入文件和刷新。文件右侧“…”提供重命名、移动和删除，也可拖动文件或目录到目标文件夹。删除实际文件使用电脑的系统回收站；项目内不再显示回收站和撤销入口。从电脑回收站恢复到原位置后，文件监听会重新识别原有文献和笔记身份。

在树中打开 Markdown 进入文档编辑器；打开 PDF 进入阅读页；其他文件提供下载。也可以使用 VS Code、Obsidian 或资源管理器创建或修改文件。页面会定期刷新，未保存草稿与磁盘发生冲突时停止覆盖并提示处理。隐藏目录、内部目录和符号链接不进入文件树。

## 论文与笔记

文献阅读页直接显示三栏：左侧为工作空间真实文件夹和 PDF，可逐级展开、按文件夹或论文名搜索；中间阅读原文，右侧记录笔记。顶部重复的工作空间工具栏已移除，空间切换使用全局侧栏。左栏右上角导入按钮可选择 PDF 保存目录，右栏“…”打开笔记路径和已有笔记关联设置。

PDF 导入时选择已有目录，按原文件名保存。外部放入的 PDF 会自动校验并出现在文献列表；相同内容保持同一文献身份。阅读页按实际所在目录分组。

打开论文不会生成空笔记。首次写入时，可修改笔记相对路径；默认位于 PDF 旁边。也可展开“关联已有 Markdown 笔记”，选择空间内已有文件。同一份 Markdown 可以在阅读页和研究计划页修改，无需复制。保留文件头的身份字段，移动后才能继续识别关联。

## 保存位置

- PDF、文档、附件：用户选定的真实目录。
- 文献和计划元数据、笔记关联、对话：`.lexivault/library.sqlite`。
- 富文本编辑缓存：`.lexivault/plan-docs/`；外部 Markdown 修改后按正文重新解析。
- 历史：`.lexivault/history/`。删除的文件位于操作系统回收站；旧版本已有的 `.lexivault/trash/` 内容保留兼容，不会自动清空。
- 本机空间登记：`%LOCALAPPDATA%\LexiVault\app.sqlite`；账号独立保存在 `accounts.sqlite`。
- 文献发现尚未连接真实下载；其目标位置选择当前空间的已有目录，不会自行创建目录。

关闭服务后复制整个工作空间可做备份，只复制 SQLite 不包含正文和附件。

## 生效

关闭旧 Python 服务，在项目根目录重新运行 `backend\.venv\Scripts\python -m backend`，刷新页面。旧数据库会先备份，再迁移到 v5 的内部位置；新空间保持空白。
